Personal profile, interactive Curriculum Vitae (CV), and open-source project portfolio for **Antonio De Gaetano** — Bioinformatician (Howest University of Applied Sciences), Biological Sciences Honours Graduate (Università degli Studi di Napoli "Parthenope"), and GNU/Linux systems developer.

🌐 **Live Website**: [https://antux912012.github.io/](https://antux912012.github.io/)

---

## 🚀 Features

- **About & Bio**: Overview of academic and professional journey spanning life sciences, laboratory analytical systems (Merck KGaA), international operational crisis triage (Etraveli Group), and systems programming.
- **Interactive Curriculum Vitae (CV)**:
  - Filterable timeline across Professional Experience and Academic Degrees.
  - One-click print/PDF export mode with a dedicated print stylesheet.
- **Technical Skills Matrix**: Comprehensive categorization of languages (Rust, Python, Vala, C/C++, Shell, SQL, LaTeX), Linux systems & kernel adaptation, native GUI frameworks (GTK4, Libadwaita, WebKitGTK 6.0, Wayland, Vulkan), and bioinformatics competencies.
- **Featured Open-Source Projects**: Filterable portfolio showcasing:
  - `sailfishos-xiaomi-libra`: Sailfish OS HADK port for Xiaomi Mi4c (Qualcomm Snapdragon 808 / MSM8992).
  - `mithrandir-rs` & `mithrandir`: Modern GNU/Linux cleaner, optimizer, telemetry and diagnostics in Rust & Python.
  - `Vingilot`: Lightweight, privacy-focused native web browser built with Libadwaita (GTK4), WebKitGTK 6.0, Wayland, and Vulkan.
  - `imladris-next-md-editor`: Native GTK4/Libadwaita Markdown editor with live WebKit preview.
  - `arda-tech-ppa`: Official Debian & Ubuntu APT PPA and Flatpak repository.
  - `debian-cachy-kernel-updater`: Automated CachyOS kernel builder and manager for Debian.
  - `vfs5011-linux-fix`: Validity VFS5011 Linux fingerprint sensor driver fix.
  - `YT-Comment-Extractor-GTK`: Desktop YouTube comment extractor using yt-dlp.
  - `LaTeX-Thesis-Parthenope`: B.Sc. Honours thesis on Microbial Fuel Cells in LaTeX.
- **Design & Performance**:
  - Zero heavy external JavaScript frameworks — blazing fast load times (< 100ms).
  - Modern, accessible Dark / Light theme switcher with OS preference detection and `localStorage` persistence.
  - Fully responsive layout optimized for mobile, tablet, and desktop screens.
  - Semantic HTML5, modern CSS3 variables, flexbox, and grid.

## 🛠️ Local Development & Testing

To test or modify the website locally:

```bash
# Clone the repository
git clone https://github.com/Antux912012/Antux912012.github.io.git
cd Antux912012.github.io

# Start a local HTTP server using Python 3
python3 -m http.server 8080
```

Then navigate to `http://localhost:8080` in your web browser.
