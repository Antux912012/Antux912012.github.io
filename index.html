About

Bridging biological sciences, NGS data pipelines, and low-level GNU/Linux systems engineering.

I am a Bioinformatics Master's student at Howest University of Applied Sciences (Kortrijk, Belgium), holding a First Class Honours B.Sc. in Biological Sciences from Università degli Studi di Napoli "Parthenope" (Naples, Italy).

Across life sciences research, ultrapure laboratory water systems at Merck KGaA, and real-time enterprise operations at Etraveli Group, my work sits where scientific rigor meets dependable systems engineering.

Outside data analysis, I develop native Linux desktop software in Rust and Vala (GTK4 / Libadwaita), maintain Debian/Ubuntu packages via Arda-Tech PPA, build custom CachyOS kernel trees, and port Sailfish OS to ARM64 hardware using the Hardware Adaptation Development Kit (HADK).

Computational Biology & Genomics
Next-Generation Sequencing pipelines, statistical genetics, sequence alignment, biological databases, and bioelectrochemical modeling.
Linux Kernel & Hardware Adaptation
Sailfish OS HADK mobile bringup, libhybris HAL integration, custom kernel patches, Scratchbox2 cross-compilation, and driver fixes.
Native Linux GUI & Tooling
Responsive desktop applications built with Rust, Vala, Python, GTK4, Libadwaita, WebKitGTK 6.0, and Wayland protocols.
